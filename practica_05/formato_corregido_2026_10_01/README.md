# Guía 05 con formato corregido

[Descargar el Word](Guia05_formato_corregido.docx) · [Leer qué se corrigió](CORRECCIONES.md)

Esta versión restaura la apertura, los títulos, la numeración, la sangría y el texto justificado del formato aportado. Los ejercicios conservan sus soluciones, resultados y fuentes directas a los archivos Java. La copia pública omite los DNI. Los signos necesarios de Java se conservan; las viñetas y comillas especiales del texto añadido se sustituyeron.

Las cuatro actividades, cuatro ejercicios propuestos y siete preguntas están completos. El propio Word distingue las observaciones de la guía de las correcciones de las respuestas.
