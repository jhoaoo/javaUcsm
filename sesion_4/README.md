# Sesion 4 - Manejo de Excepciones

Codigo correspondiente a la Practica N.° 04 de Lenguajes de Programacion III.

## Orden de la sesion

### Experiencias
1. `experiencia_1/Experiencia1.java` - Excepciones internas y validacion de datos.
2. `experiencia_2/Experiencia2.java` - Excepciones personalizadas.
3. `experiencia_3/Experiencia3.java` - Limites de credito y propagacion de excepciones.
4. `experiencia_4/Experiencia4.java` - Reportes de transacciones y manejo de recursos.

### Ejercicios propuestos
1. `ejercicio_1/Ejercicio1.java` - Excepciones de vocal, numero, blanco y salida.
2. `ejercicio_2/Ejercicio2.java` - Calculadora basica.
3. `ejercicio_3/Ejercicio3.java` - Biblioteca de libros.
4. `ejercicio_4/Ejercicio4.java` - Gestion de numeros negativos.
5. `ejercicio_5/Ejercicio5.java` - Registro de estudiantes.
6. `ejercicio_6/Ejercicio6.java` - Registro de contactos.
7. `ejercicio_7/Ejercicio7.java` - Registro de transacciones inmobiliarias.
8. `ejercicio_8/Ejercicio8.java` - Tematica libre: reservas de laboratorio de computo.

### Cuestionario
- `cuestionario_9/Cuestionario9.java` - Ejemplo de excepciones suprimidas en `try-with-resources` para la pregunta 9.

Los programas fueron preparados para compilarse de forma independiente con Java 21.
