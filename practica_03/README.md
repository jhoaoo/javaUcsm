# Practica N.° 03 - Principios SOLID en Java

Curso: Lenguajes de Programacion III  
Universidad Catolica de Santa Maria  

## Contenido

- `actividad_1_lsp`: sustitucion de Liskov con `Vehiculo`, `Coche` y `Bicicleta`.
- `actividad_2_srp`: separacion de las notificaciones por correo y SMS.
- `actividad_3_ocp`: calculo de danio extensible para espada, arco y hacha.
- `actividad_4_juego_solid`: combate con armas, elementos y golpes criticos.
- `ejercicio_reservas_hotel`: sistema integrado de reservas que aplica SRP, OCP, LSP, ISP y DIP.

## Compilacion y ejecucion

Cada carpeta es independiente. Por ejemplo, para ejecutar la Actividad 1:

```bash
cd actividad_1_lsp
javac *.java
java Principal
```

Para ejecutar los otros modulos, se usa `java Main` o `java Juego`, segun el nombre de la clase principal de cada carpeta.
